# java-explore-with-me
Template repository for ExploreWithMe project.
Ссылка на ПР - https://github.com/Amirdjan94/java-explore-with-me/pull/4

### Описание работы дополнительного функционала 

#### Авторизованный пользователь 
1. Создание комментария - **"POST /users/{userId}/events/{eventId}/comment"**
  - Владелец события не может комментировать событие
  - После создания, комментарий принимает статус PENDING

2. Удаление комментария - **"DELETE /users/{userId}/comment/{commentId}"**
   - Удалить комментарий может только его владелец

3. Обновление комментария - **"PATCH /users/{userId}/comment/{commentId}"**
   - Обновить комментарий может только его владелец

4. Получение полной информации о комментарии добавленным текущим пользователем - **"GET /{userId}/comment/{commentId}"**
5. Получение списка комментариев по ID события - **"GET /users/events/{eventId}/comments"**
   - Возвращаются только опубликованные комментарии
   - from - количество комментарий, которые нужно пропустить для формирования текущего набора
   - size - количество комментарий в наборе

#### Админ

1. Получение списка комментариев по ID события - **"GET /admin/events/{eventId}/comments""**
    - Возвращаются только опубликованные комментарии
    - status - состояние в которых находятся искомые комментарии
    - from - количество комментарий, которые нужно пропустить для формирования текущего набора
    - size - количество комментарий в наборе
2. Изменения статуса комментария (отклонение/публикация) - **"PATCH /admin/comment/{commentId}"**
